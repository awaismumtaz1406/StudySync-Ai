## README.md Content

# StudySync-AI 🚀

StudySync-AI is a modern, AI-powered university helper web application built to streamline the study workflow for students. It features slide deck upload and parsing support, allowing learners to extract, analyze, and interact with course content effortlessly.

## 🛠️ Tech Stack
- **Framework & Runtime:** TypeScript, Node.js, Bun
- **Frontend & UI:** React, Vite, Tailwind CSS
- **AI Integration:** Google Gemini API / LangChain workflows
- **Deployment:** Vercel

## 📂 Project Structure
- `/api` - API entry points and server routing handlers.
- `/server` - Backend server logic, slide deck parsing engines, and middleware.
- `/src` - Frontend client components, views, and state management.
- `server.ts` - Main server orchestration file.
- `vercel.json` - Deployment configuration for Vercel.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+) or Bun installed
- Google Gemini API key

### Installation
1. Clone the repository:
   ```bash
   git clone [https://github.com/awaismumtaz1406/StudySync-Ai.git](https://github.com/awaismumtaz1406/StudySync-Ai.git)
   cd StudySync-Ai

```

2. Install dependencies:
```bash
bun install
# or
npm install

```


3. Set up your environment variables:
Copy `.env.example` to `.env` and configure your API keys.
4. Run the development server:
```bash
npm run dev

```
